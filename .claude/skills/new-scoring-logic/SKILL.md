# スコアリング変更手順

`.claude/rules/quality-process.md` の4段階を、次の具体手順で行う。

1. 対象関数と入力を整理し、数行のサンプル価格・出来高データを作る。
2. 手計算した期待値を表で提示する（式と途中経過つき）。
3. 同じ内容を pytest のテストケース案として提示し、**オーナーの承認を待つ**。
4. 承認後に `analysis/` を実装し、`tests/` にテストを追加する（買い/売り対称のものは両方）。
5. `python -m pytest tests/` を全件実行して結果を報告する。
